🤖 Rule-Based AI Chatbot (Flask + JavaScript)

A simple web-based rule-based AI chatbot built using Python (Flask) for the backend and HTML + JavaScript for the frontend.

This project demonstrates:

Control flow (if / elif / else)

Decision-making logic

Basic AI concepts (rule-based system)

Frontend ↔ Backend communication

JSON handling

Web development fundamentals

📌 Project Objective

The goal of this project is to:

Improve control flow understanding

Practice decision-making logic

Learn how web applications communicate

Build a basic AI chatbot using rules (not ML)

This is suitable for beginners and internship-level AI projects.
